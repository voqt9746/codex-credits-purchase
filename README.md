# Codex 额外积分购买：先看官方 Credits 入口，再判断是否需要其他订阅服务

Codex 用量见底时，最直接的问题通常是：能不能单独买 Credits，买完是否马上能继续工作？答案取决于你的 ChatGPT 账号、套餐和当前可用的购买选项。对符合条件的 Plus 或 Pro 用户，OpenAI 提供了在不更改现有套餐的情况下购买额度的方式；具体价格、可买面额和支付方式要以登录后的 Usage 页面为准。

这里有个容易混淆的地方：提供的 WildAI 链接页面介绍的是 ChatGPT Plus/Pro、Claude Pro/Max 等订阅服务，并未显示 Codex Credits 商品或对应价格。因此，**不能把购买会员订阅直接说成购买 Codex 额外积分**。如果你的目标只是 Codex 超出套餐包含用量后继续使用，先检查 OpenAI 账户里的官方 Credits 入口，再决定下一步。

## Codex 额外积分是什么，和会员、API 余额有什么区别？

Codex Credits 是套餐包含用量耗尽后，用于继续使用受支持功能的额外额度。购买 Credits 不会自动把 Plus 升级成 Pro，也不会改变现有订阅套餐。

它也不是 OpenAI API 余额。API 余额用于开发者平台的 API 调用，通常通过 API Key 和开发者平台账单管理；ChatGPT/Codex Credits 则在 ChatGPT 或 Codex 的用量页面查看。两套余额不能当成同一笔钱使用。

| 你要处理的需求 | 对应选项 | 到哪里核对 |
| --- | --- | --- |
| Codex 套餐额度用完，想继续使用 | 购买可用的 Codex Credits | ChatGPT 设置中的 Usage，或 Codex 的 Usage / Billing |
| 想获得更多套餐内功能和用量 | 比较 ChatGPT 套餐 | ChatGPT 套餐与定价页面 |
| 用 API Key 在程序中调用模型 | API 计费与余额 | OpenAI 开发者平台的 Billing / Usage |

对于 Plus 和 Pro，Codex 与部分其他支持的 ChatGPT 功能可能共用 agentic 用量额度。实际扣费会受模型、任务复杂度、上下文和使用功能影响，所以不能简单把“多少条任务”换算成固定的 Credits 数量。

## 怎么购买 Codex 额外积分？

符合条件的账户可以从 ChatGPT 的 **Settings → Usage**，或 Codex 应用中的 **Usage & Billing** 查看余额和购买选项。达到用量限制时，页面也可能显示添加 Credits 的入口。

可以按下面顺序操作：

1. 登录准备使用 Codex 的 ChatGPT 账户。
2. 打开 Usage 或 Usage & Billing，确认当前账户、个人或团队工作区，以及剩余用量和重置时间。
3. 如果页面显示添加 Credits 的选项，查看购买面额、价格、币种、付款方式和结算金额。
4. 付款前检查是否启用了自动购买，并确认订单对应的是正确账户。
5. 完成购买后回到同一账户的用量页面，核对余额和近期记录。

官方购买资格、可购买金额和价格可能因账号、地区及套餐而异。部分 Free 或 Go 账户也可能看到购买入口，但并非所有账户都开放。如果页面没有 **Add credits**，就不能据此认定一定可以购买；应以当前账户实际显示为准。

## 买之前先看重置时间和自动购买设置

额度用完不一定意味着需要立刻付款。先查看页面给出的重置时间：如果很快恢复，等额度重置可能更合适；如果正赶项目节点，再比较手动购买 Credits 和升级套餐的成本。

如果账户提供自动充值功能，系统可在余额低于设定阈值时，使用默认付款方式补到目标余额。启用时若余额已经低于阈值，也可能立即触发购买。偶尔用量突增的人，手动购买更容易控制支出；确实长期高频使用，才值得进一步比较更高套餐或适合团队的计费方式。

付款前尤其要留意两点：

- **核对结算页金额。**可购买面额、税费和支付方式按账户页面显示为准，不宜照搬其他用户的截图或旧价格。
- **检查自动购买状态。**一次性手动购买和自动充值不是同一设置，确认付款前的选项，避免后续产生预期之外的扣款。

## Credits 的有效期、退款和共享规则

购买前值得查看 Credits 的使用条款。OpenAI 当前帮助信息说明，购买的 Credits 自购买之日起有效 **12 个月**；未使用余额到期后不结转。Credits 通常不可退款，只有适用法律、合同规定或经核实的特定账单问题等情形可能例外。

Credits 也不能转让、转售或赠送。因此，所谓“把别人的现有余额转到你的账号”并不是普通的 Credits 购买流程。付款前要确认目标账户正确；如果是团队工作区，则还要确认额度归属和管理员设置。

如果页面提供钱包余额支付选项，也不要默认钱包余额一定能用于 Credits。结账时确认它是否实际抵扣，以及最终还需支付多少。

## 买了但没到账，先按这几项排查

支付成功提示不等于已经确认目标账户的 Credits 余额更新。建议回到 Usage 页面核对：

- 是否登录了购买时使用的同一个账号；
- 当前查看的是个人账户还是正确的团队工作区；
- Credits 余额或购买记录是否发生变化；
- 订单是否仍在处理中；
- 是否有并行任务造成余额变化或负余额。

若页面暂未更新，可刷新或重新登录，并保存订单凭证和余额截图。不要在状态不清楚时连续重复付款。如果核对后仍有问题，按实际购买渠道联系对应支持团队，并提供购买时间、账户和订单信息；截图中不要暴露密码、API Key 或其他敏感凭据。

## WildAI 适合解决什么，不适合解决什么？

用户提供的 WildAI 页面介绍 ChatGPT Plus/Pro、Claude Pro/Max 等订阅服务，并提到微信、支付宝支付。它可以作为相关订阅服务的查询入口，但当前可见页面并未证明它提供可直接购买的 Codex Credits 套餐，也没有足够公开信息确认 Codex 积分的面额、价格或具体到账方式。

所以，判断很简单：

- **只需要额外 Codex 用量：**先检查 ChatGPT 设置中的 Usage 或 Codex 的 Usage & Billing。
- **准备办理会员订阅：**通过推广入口查看实际展示的商品详情、账单和服务规则，别把“订阅会员”和“购买 Credits”混为一谈。
- **账号没有官方购买入口：**先确认套餐、地区和工作区资格；不要仅凭第三方页面上的“额度”“充值”等字样推定它等同于 OpenAI 官方 Credits。

当你在核对服务或其他 AI 订阅选项时，可以打开 [👉 查看 WildAI 当前展示的服务](https://bit.ly/Bewild)，再以页面实际商品与结算信息为准。

## 常见问题

### Codex 用量用完后一定要升级 Pro 吗？

不一定。符合条件的 Plus 或 Pro 用户可能可以单独购买 Credits；也可以查看额度重置时间，等用量恢复。选择哪种方式要看账户实际提供的选项和你的使用频率。

### 为什么我看不到购买 Credits 的按钮？

购买功能并非对所有账号、地区和套餐统一开放。先检查登录账户、工作区和用量页面；如果入口仍未显示，就以该账户当前资格为准。

### Codex Credits 能当 API 余额用吗？

不能。Credits 与 API 余额分别用于不同的计费体系。若遇到 API Key 的额度或账单错误，应到开发者平台核对 API 计费，而不是购买 ChatGPT/Codex Credits。

### 购买后会马上从余额扣除吗？

套餐包含的用量通常先使用。只有达到适用限制后，支持的功能才会开始消耗 Credits；因此，购买后余额暂时没有减少，不代表没有到账。

### Credits 会过期吗？

OpenAI 当前说明为购买日起有效 12 个月，未使用余额到期后不结转。购买当天仍应检查账户页面显示的最新条款。

**结论：**搜索“Codex 额外积分购买”时，优先确认自己的 Usage 页面有没有官方购买选项，并核对账号、重置时间、价格和自动充值状态。WildAI 链接当前展示的是 AI 订阅服务信息，不能据此认定它售卖 Codex Credits。
